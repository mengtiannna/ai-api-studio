# AI API Studio

一个轻量、简洁的个人 AI API 管理与使用平台，支持自定义 API 地址（Base URL）、API Key 和模型配置，方便统一管理不同 AI 服务商的 API 接口。

无需绑定特定 AI 服务商，即可灵活接入兼容接口规范的 AI 服务，快速切换不同模型，打造属于自己的 AI 工作台。

## ✨ 功能特性

- **自定义 API 配置**：支持配置 API 地址、API Key 和模型信息。
- **多服务商管理**：支持添加和管理多个 AI 服务配置。
- **模型灵活切换**：根据需求自由切换不同服务商及模型。
- **API 连通性测试**：快速验证接口配置及服务可用性。
- **配置持久化**：保存个人配置，减少重复操作。
- **数据安全**：支持本地配置管理，降低敏感信息泄露风险。

## 🎯 项目目标

打造一个开放、灵活、可扩展的个人 AI 工作台，让 AI 服务接入更加简单，让模型管理更加自由。
